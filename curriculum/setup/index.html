Setting Up

Do this once, before Lesson 01. It is a short check: you already have almost everything from the Java course. Spring itself arrives in Lesson 01, and the database tooling later, in Phase 4.

Check your tools

In a terminal, run:

java -version
mvn -version
git --version

Where your code lives

You keep working in your own repository, the one with your farm code. Copy this curriculum's curriculum/ folder next to it (or into it) so you can read the lessons while you build. You don't start a new project: Lesson 02 turns the one you have into a Spring Boot application.

Copilot rules

Your repo already has Copilot instructions from the Java course. You'll get an updated version for this course to merge in; until it arrives, the rule is the old one plus a new line: Copilot never writes a controller, a test, or a SQL query for you.

Git workflow

Unchanged from the Java course: one commit per green test, with the prefixes feat:, test:, refactor:, fix:.

git add .
git commit -m "feat: GET /pens returns all pens"

Coming later

Podman and PostgreSQL are set up at the start of Phase 4. Nothing to install for them now.

Ready? Head back to the curriculum home. Start with Lesson 01.
